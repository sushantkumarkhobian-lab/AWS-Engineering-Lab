# ☁️ S3 Presigned URL Upload System

Securely upload files directly from a web application to **Amazon S3** using **Presigned URLs** generated by a Node.js backend. This project demonstrates how modern applications enable secure client-side uploads without exposing AWS credentials.

---

## 📖 Overview

Traditional applications often upload files through the backend server, increasing server load and bandwidth usage.

This project uses **Amazon S3 Presigned URLs**, allowing clients to upload files **directly to S3** while the backend only generates a temporary, secure upload link.

This architecture is widely used in production systems for document management, profile picture uploads, media storage, and cloud applications.

# 🚀 Features

- Generate secure Amazon S3 Presigned URLs
- Upload files directly from the browser to S3
- Backend never handles file data
- Temporary upload links with expiration
- Secure IAM-based authentication
- Modern responsive UI
- Real-time upload status

# 🏗️ Architecture

```
                +----------------+
                |    Browser     |
                +-------+--------+
                        |
          Request Upload URL
                        |
                        ▼
              +------------------+
              |  Express Backend |
              +------------------+
                        |
```

## 🔒 Amazon S3 CORS Configuration

The `cors-config.json` file contains the CORS policy used for the Amazon S3 bucket. Apply this configuration under:

**Amazon S3 → Your Bucket → Permissions → Cross-origin resource sharing (CORS)**

This enables secure browser-based uploads using Amazon S3 Presigned URLs.

---

# 🔄 Workflow

1. User selects a file.
2. Frontend requests a Presigned URL from the backend.
3. Express generates a temporary upload URL using AWS SDK.
4. Frontend uploads the file directly to Amazon S3.
5. File is securely stored in the configured bucket.

---

# 🔐 Security

Instead of exposing AWS credentials in the frontend:

- IAM credentials remain on the server.
- Backend generates a temporary upload URL.
- URL expires automatically after a few minutes.
- Browser uploads directly to Amazon S3.

This follows AWS security best practices.

# 🛠️ Installation

## Clone the repository

```bash
git clone https://github.com/yourusername/S3-Presigned-Upload.git
```

---

## Install dependencies

```bash
cd backend
npm install
```

---

## Configure Environment Variables

Create a `.env` file inside the backend directory.

```env
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=YOUR_ACCESS_KEY
AWS_SECRET_ACCESS_KEY=YOUR_SECRET_KEY
S3_BUCKET_NAME=YOUR_BUCKET_NAME
PORT=3000
```

---

## Start the server

```bash
node server.js
```

Server starts at

```
http://localhost:3000
```
